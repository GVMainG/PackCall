# Правила домена

Этот документ описывает правила кампаний, получателей и доставок, реализованные в Core. Состояние подключения Core к приложениям указано в [Компонентах](./Компоненты.md).

## Сущности

- **Кампания** объединяет сообщение и доставки. Новая кампания создаётся как черновик. Создание ещё одной кампании с теми же данными не считается повтором первой.
- **Получатель** идентифицируется по `Id` и имеет адрес электронной почты. При создании кампании для каждого уникального `Id` из полученной аудитории создаётся одна доставка. Аудитория может быть пустой.
- **Доставка** относится к одной кампании и одному получателю. Она хранит адрес получателя как снимок: последующее изменение адреса у получателя не меняет адрес уже созданной доставки.

## Состояния кампании

| Состояние | Допустимое следующее состояние | Правило |
| --- | --- | --- |
| `Draft` | `InProgress` | Название и текст сообщения должны быть заполнены при запуске. |
| `InProgress` | `Completed` | Завершение возможно, когда нет ожидающих или обрабатываемых доставок. |
| `Completed` | Нет | Повторный запуск запрещён. |
| `Failed` | Нет | Значение есть в перечислении, но текущая логика не переводит кампанию в него. |

Черновик разрешено создать с незаполненными названием и текстом сообщения. Изменять эти поля можно только у черновика; при изменении оба поля должны быть заполнены. Повторный запуск уже запущенной кампании не меняет состояние и даты. Повторная проверка уже завершённой кампании тоже не меняет даты. Удаление запрещено только для кампании `InProgress`: текущий сервис допускает удаление при любом другом статусе, включая `Completed` и недостижимый сейчас `Failed`.

## Состояния доставки

| Состояние | Допустимое следующее состояние | Правило |
| --- | --- | --- |
| `Waiting` | `InProgress` | Доставка захватывается для обработки. |
| `InProgress` | `Sent`, `Failed`, `Waiting` | Успех отправки даёт `Sent`, явная ошибка — `Failed`. Возврат в `Waiting` допускает повторную обработку. |
| `Sent`, `Failed` | Нет | Конечные состояния; повторная обработка запрещена. |

Обрабатывать доставку можно только в `InProgress` и только при кампании `InProgress`. При переходе доставки в `Sent` или `Failed` фиксируется время завершения. Ошибочная доставка считается завершённой: `Failed` не препятствует завершению кампании. Запущенная кампания без доставок также может стать `Completed` при проверке завершения.

Правила реализованы в [Campaign](../../src/PackCall.Core/Entities/Campaign.cs), [Delivery](../../src/PackCall.Core/Entities/Delivery.cs), [CampaignService](../../src/PackCall.Core/Services/CampaignService.cs) и [DeliveryProcessingService](../../src/PackCall.Core/Services/DeliveryProcessingService.cs).
