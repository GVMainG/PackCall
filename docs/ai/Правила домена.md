# Правила домена

Этот документ описывает правила кампаний, получателей и доставок, реализованные в Core. Состояние подключения Core к приложениям указано в [Компонентах](./Компоненты.md).

## Сущности

- **Кампания** объединяет сообщение и доставки. Сущность создаётся как черновик; на время формирования доставок сценарий переводит её в `Forming` и возвращает в `Draft` после завершения. Создание ещё одной кампании с теми же данными не считается повтором первой.
- **Получатель** идентифицируется по `Id` и имеет уникальный адрес электронной почты. Перед созданием сервис обрезает пробелы и приводит email к нижнему регистру; пустой, некорректный или длиннее 255 символов адрес отклоняется. Повторный адрес после нормализации отклоняется. При создании кампании для каждого уникального `Id` из полученной аудитории создаётся одна доставка. Аудитория может быть пустой.
- **Доставка** относится к одной кампании и одному получателю. Она хранит адрес получателя как снимок: последующее изменение адреса у получателя не меняет адрес уже созданной доставки.

## Состояния кампании

| Состояние | Допустимое следующее состояние | Правило |
| --- | --- | --- |
| `Draft` | `Forming`, `InProgress` | Формирование блокирует изменение и запуск; для запуска название и текст сообщения должны быть заполнены. |
| `Forming` | `Draft` | После создания всех доставок кампания снова становится доступной. |
| `InProgress` | `Paused`, `Completed` | Кампанию можно приостановить; завершение возможно, когда нет ожидающих или обрабатываемых доставок. |
| `Paused` | `InProgress` | Возобновление сохраняет дату первого запуска; при отсутствии незавершённых доставок кампания затем сразу завершается. |
| `Completed` | Нет | Повторный запуск запрещён. |
| `Failed` | Нет | Значение есть в перечислении, но текущая логика не переводит кампанию в него. |

Черновик разрешено создать с незаполненными названием и текстом сообщения. Изменять эти поля можно только у черновика; при изменении оба поля должны быть заполнены. Повторный запуск уже запущенной кампании не меняет состояние и даты. Запуск черновика и возобновление после паузы — отдельные операции: запуск кампании в `Paused` запрещён. Повторная проверка уже завершённой кампании тоже не меняет даты.

Пауза допустима только для `InProgress`; повторная пауза кампании в `Paused` не меняет даты. Возобновление переводит `Paused` в `InProgress`, обновляет дату изменения и сохраняет дату первого запуска. Для уже запущенной кампании операция возобновления также доступна и проверяет, не завершились ли все доставки. Для черновика и конечных состояний пауза и возобновление запрещены.

Пауза останавливает начало следующих отправок после проверки состояния кампании. Уже начатая отправка может завершиться и получить конечный результат. Ещё не отправленная доставка из захваченного пакета при обнаружении паузы возвращается в `Waiting`; её идентификатор воркера и срок закрепления очищаются. Такие доставки сохраняются для возобновления. Приостановленная кампания остаётся в `Paused`, даже если последняя начатая отправка завершилась; операция возобновления завершит её, если незавершённых доставок больше нет.

Удаление запрещено для `InProgress` и `Paused`. Текущий сервис допускает удаление при любом другом статусе, включая `Forming`, `Completed` и недостижимый сейчас `Failed`.

## Состояния доставки

| Состояние | Допустимое следующее состояние | Правило |
| --- | --- | --- |
| `Waiting` | `InProgress` | Доставка захватывается для обработки. |
| `InProgress` | `Sent`, `Failed`, `Waiting` | Успех отправки даёт `Sent`, явная ошибка — `Failed`. Возврат в `Waiting` возможен для неотправленной доставки при обнаружении паузы или для незавершённой доставки после истечения закрепления. |
| `Sent`, `Failed` | Нет | Конечные состояния; повторная обработка запрещена. |

Начать отправку можно только для доставки в `InProgress` и при кампании `InProgress`. При кампании `Paused` обработка захваченной доставки освобождает её для возобновления, не начиная отправку. При переходе доставки в `Sent` или `Failed` фиксируется время завершения, очищаются идентификатор воркера и срок закрепления. Ошибочная доставка считается завершённой: `Failed` не препятствует завершению кампании.

Проверка завершения переводит только `InProgress` в `Completed`, если нет доставок в `Waiting` или `InProgress`. Сам запуск такую проверку не вызывает: пустая кампания после запуска остаётся в `InProgress`. Проверка выполняется после обработки доставки, при явном вызове проверки завершения и в операции возобновления.
