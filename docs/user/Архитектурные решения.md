
# Использование доменных сущностей в EF

`AppDbContext` напрямую использует сущности `Campaign`, `Recipient` и `Delivery` из `PackCall.Core`.

Отдельные сущности для работы с базой данных не добавлены, потому что на этапе MVP структура доменной модели совпадает со структурой хранения. Дополнительные модели потребовали бы дублирования классов и постоянного преобразования данных, не решая текущих задач.

`PackCall.Core` при этом не зависит от Entity Framework или PostgreSQL: вся конфигурация таблиц, связей и индексов остаётся в `PackCall.Infrastructure`.

Решение следует пересмотреть, если структура базы данных начнёт существенно отличаться от доменной модели или требования хранилища начнут влиять на бизнес-логику.
