# Гарантии PackCall — матрица as-is

Матрица описывает реализацию beta.3. Формирование поддерживает email и Telegram,
отправка доступна через тестовый оператор email. Статус `Sent` подтверждает приём
оператором канала. Доставка конечному получателю остаётся за пределами этой гарантии.
Результаты SM-2 и SM-6 относятся к указанным в отчётах ревизиям. Допуск к выпуску
проверяется отдельно по обязательному `CI required` для коммита выпуска.
[Правила допуска и evidence](EVIDENCE.md).

| Гарантия | Формулировка (as-is) | Проверка | Команда | Условия / ограничения |

| **FR-3 / FR-16** канал и маршрутизация | Захват включает доставки активных кампаний с зарегистрированным каналом и непустым сохранённым адресом. Воркер выбирает keyed-оператор по каналу доставки и передаёт снимок адреса. При отсутствии оператора для захваченной доставки её закрепление сохраняется до восстановления. Запуск кампании возвращает `409`, если её канал недоступен | unit TestOperatorTests; integration OperatorPostgresTests, ChannelsApiPostgresTests | `dotnet test tests/PackCall.Test --filter "Module=Operators&#124;Module=Channels"` (нужен `PACKCALL_TEST_POSTGRES`) | Реестр включает тестовый email-оператор. Подключение Telegram запланировано на `beta.4` |
| **FR-9** выборка | Сначала сохраняются выбранные контакты и каналы. При формировании создаётся одна доставка для каждой выбранной пары с адресом. Worker использует сохранённый адрес и после его замены у контакта | `CampaignAudiencePostgresTests`, `CampaignLifecyclePostgresTests`, `ChannelsApiPostgresTests`. [Результат SM-2](evidence/beta3/sm2-audience.md) | [Запуск SM-2](../tests/README.md) | Проверены восемь комбинаций выбора контакта, канала и наличия адреса. Смешанная кампания без оператора Telegram получает `409` при запуске и остаётся в `Draft` без вызовов оператора |
| **FR-10** результат попытки | Подтверждённый приём даёт `Sent`, подтверждённый отказ даёт `Failed`, если закрепление ещё действует. Неизвестный исход, например таймаут или некорректный ответ, оставляет доставку в `InProgress` до recovery (NFR-2) | `DeliveryProcessingServiceTests`, `DeliveryResultLeasePostgresTests`. [Результат SM-2](evidence/beta3/sm2-audience.md), [результат SM-6](evidence/beta3/sm6-recovery.md) | [Запуск SM-6](../tests/acceptance/workers/sm6/README.md) | Попытка вызова и HTTP 200 сами по себе не подтверждают приём. HTTP-адаптер проверяет допустимую пару `result/code` |
| **FR-11** захват/восстановление | Worker захватывает доставки пакетами. Recovery возвращает просроченную доставку в `Waiting` с тем же ID. Обновление результата по устаревшему закреплению отклоняется | `WorkerPostgresTests`, W22 (независимые процессы). [Результат SM-6](evidence/beta3/sm6-recovery.md) | [Запуск W22](../tests/acceptance/workers/coordination/README.md), [запуск SM-6](../tests/acceptance/workers/sm6/README.md) | Потеря подтверждения или остановка Worker до фиксации результата могут привести к повторному вызову оператора после recovery |
| Запуск и удаление | Запуск черновика проверяет сохранённые каналы. Повторный запуск в `InProgress` сохраняет `startedAt`. PostgreSQL отклоняет удаление в `InProgress` и `Paused`. Допустимое удаление очищает снимок и доставки, сохраняя журнал | `CampaignLifecyclePostgresTests`, `ChannelsApiPostgresTests` | `dotnet test tests/PackCall.Test --filter "Category=Integration"` | Пустой снимок каналов исторической кампании допустим |
| **FR-12** пауза/resume | Пауза блокирует новые захваты, начатые отправки могут завершиться. Resume продолжает оставшиеся доставки с прежними ID и `startedAt` | `CampaignPausePostgresTests` | `dotnet test tests/PackCall.Test --filter "Category=Integration&Module=Campaigns"` | Неотправленный хвост освобождается владельцем закрепления |
| **FR-13** завершение | После фиксации результата доставки и при каждом проходе recovery Worker завершает кампанию в `InProgress`, если нет доставок в `Waiting` и `InProgress`. Сверка сохраняет `startedAt` и однократно заполняет `completedAt`. При том же условии запуск и возобновление сразу возвращают `Completed` с обеими датами | `WorkerPostgresTests`, `CampaignPausePostgresTests`, `ChannelsApiPostgresTests`. [Сверка завершения в SM-6](evidence/beta3/sm6-recovery.md#сверка-завершения) | `dotnet test tests/PackCall.Test --filter "Category=Integration"` | Исторические доставки без адреса учитываются по статусу. Сверка обновляет только кампанию |
