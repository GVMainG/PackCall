# Архитектурные решения (ADR)

Каждое значимое решение оформляется отдельным файлом `NNNN-<краткое-название>.md` с контекстом,
решением и последствиями. `NNNN` — следующий свободный номер: перед созданием ADR проверьте
каталог, чтобы два параллельно написанных ADR не получили один номер. Решения Epic 1 —
Stories 1.16–1.18 (модель контакта и каналов, legacy-кампании при миграции, режимы Telegram и
профиль multi-worker/1M). ADR не переопределяют архитектурную спину (AD-1…AD-8), а фиксируют
выбор в её рамках.
