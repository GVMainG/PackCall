# Evidence

Доказательства результатов и гарантий по тегам: `docs/evidence/<tag>/`. Каждый артефакт содержит
commit SHA, версию окружения и команду воспроизведения; правила — в `../EVIDENCE.md`. В `beta.2`
здесь появятся `beta2/` (ремонт приёмки и CI-гейты; соответствует тегу `v0.5.0-beta.2`) и
`necessity-audit/` (тематический каталог переиздания аудита необходимости тестов). Сырые
многогигабайтные артефакты в Git не хранятся — только ссылка и команда воспроизведения.
