# PackCall v0.5.0-beta.2

Annotated-тег `v0.5.0-beta.2` указывает на коммит
`113d228b6803f9a2b2c98a007925764dc3f5b7b2` в истории `gv`.
Выпуск согласован владельцем без GitHub CI.
[Отчёт готовности](../evidence/beta2/release-readiness.md).

## Что вошло

- Единый C#-проект тестов, обязательные проверки сборки, Unit, PostgreSQL Integration, Python и Docker, проверка `CI required` по SHA перед тегом. [CI и локальная разработка](../../README.md#ci).
- Воспроизводимые прогоны SM-6 A/B/C для неизвестного ответа оператора, остановки Worker и попытки записи по старому закреплению. [SM-6 A](../evidence/beta2/SM-6-A.md), [SM-6 B/C](../evidence/beta2/SM-6-B-C.md).
- Переизданный necessity-аудит, OpenAPI baseline, матрица действующих гарантий и ADR для последующих вех. [Аудит](../evidence/necessity-audit/README.md), [OpenAPI](../api/README.md), [гарантии](../guarantees.md), [ADR](../adr/README.md).
- Инструменты замеров и анализа производительности, появившиеся после `beta.1`. [Команды и статус MEAS](../../scripts/performance/README.md).

## Исправления после `beta.1`

- Worker записывает предупреждение об истечении закрепления в UTF-8. Приёмка снова находит его в логах. [RUN-6](../evidence/beta2/RUN-6.md).
- Пустой или отсутствующий `TEST_SIMULATE_ERRORS` в Compose теперь означает `false`. Lifecycle-приёмка передаёт обязательные настройки при прямом `docker run` и проверяет `Failed=-1`. Повторно пройдены проверки конфигурации, старта, остановки и перезапуска API. [RUN-4/GAP-01](../evidence/beta2/RUN-4-GAP-01.md), [RUN-2](../evidence/beta2/RUN-2.md), [RUN-5](../evidence/beta2/RUN-5.md).
- `RuntimeSampler` маркирует откат UTC внутри замера и между замерами. Повторный stall smoke проходит. [GAP-03](../evidence/necessity-audit/coverage-gaps.md#stall-smoke-story-19).

## Что не вошло

Новая модель контактов, выборка контактов и каналов, миграция legacy-кампаний,
Telegram и приёмка на 1 млн доставок относятся к следующим вехам. Новый
300k baseline с проверкой MEAS-1…MEAS-4 выполняется в Story 2.1 на коммите тега.
[ADR](../adr/README.md), [план замеров](../../scripts/performance/README.md).

## Известные ограничения

- Доступен тестовый email-оператор. `Sent` означает подтверждённый приём оператором. При потере результата внешний вызов может повториться. [Гарантии](../guarantees.md).
- В API нет аутентификации. Стенд рассчитан на локальный запуск и демо. [Ограничения OpenAPI](../api/README.md#известные-ограничения-baseline-beta2).
- OpenAPI описывает текущий контракт `recipients`. В схеме статусы представлены числами, а в ответах API используются PascalCase-строки. [Ограничения OpenAPI](../api/README.md#известные-ограничения-baseline-beta2).
- Остаются пробелы в проверке журнального `Failed=-1` в shutdown probe и в чтении замеров с перекрывающимися монотонными границами. Решения по GAP-02 и GAP-04 записаны для Stories 2.14 и 2.15. [Пробелы покрытия](../evidence/necessity-audit/coverage-gaps.md).
- Исторический прогон 300k был выполнен с одним Worker и не закрывает MEAS-1…MEAS-4. [Статус измерений](../../scripts/performance/README.md).
