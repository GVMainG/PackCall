# PackCall v0.5.0-beta.3

Выпуск из ветки `gv` согласован владельцем по результатам локальной регрессии.
Проверенные исходники — `6209783f4b5d68babe342b4eeae9eec6eeef91bc`.
Для этого выпуска владелец снял требования к подтверждению производительности
и GitHub CI. Результат замера остаётся `inconclusive`.
[Локальная регрессия и решение о выпуске](../evidence/beta3/release-readiness.md).

## Изменения

- Контакты поддерживают email и Telegram chat ID. API добавляет
  `GET /api/channels`, `GET/POST /api/contacts` и `GET/PATCH /api/contacts/{id}`.
  Маршруты `/api/recipients` продолжают работать с email-контактами.
- В ответах доставки `recipientId` идентифицирует контакт, а `recipientEmail`
  содержит снимок адреса доставки. Для доставки по каналу Telegram в этом поле
  может быть chat ID. Фактическая отправка в beta.3 доступна только по email.
- **Несовместимое изменение.** Создание кампании требует `selection` и `channels`
  вместе с `name` и `messageText`. Для прежней рассылки всем email-контактам
  добавьте `"selection":"all","channels":["email"]`. Для явной выборки передайте
  `"selection":"contactIds"` и непустой массив UUID `contactIds`.
- `POST /api/campaigns` возвращает `201` с `Location` после формирования
  доставок и перехода в `Draft`. Ответ `400` описывает ошибки валидации.
  Ответ `500` описывает сбой формирования. Детали кампании содержат сводку
  `formation`. [Сверка OpenAPI](../evidence/beta3/openapi-diff.md).
- Worker выбирает оператора по каналу сохранённой доставки и отправляет по
  сохранённому адресу.
- Исправлено восстановление завершения кампании после сбоя между записью
  результата последней доставки и обновлением кампании. Сверка при старте
  Worker и по интервалу переводит такую кампанию в `Completed`.
  [Гарантии](../guarantees.md).

## Чистая установка и обновление

Запустите новый Compose-проект с пустым томом PostgreSQL. Migrator применит
миграции перед запуском API и Worker. При переходе с beta.2 данные остаются
в старом томе у владельца и не переносятся в новый проект. Гарантия сохранения
при обновлениях начинается с данных, созданных в 1.0.
[Быстрый старт](../../README.md#быстрый-старт-compose).
[Обновление](../../README.md#обновление-с-beta2-до-beta3).

## Ограничения

- Доступен тестовый email-оператор. `Sent` фиксирует подтверждение оператора.
  После потери результата внешний вызов может повториться. Отправка через
  Telegram запланирована на beta.4. Запуск кампании без оператора для выбранного
  канала возвращает `409`.
- Статусы в ответах JSON представлены строками PascalCase. OpenAPI декларирует
  `CampaignStatus` и `DeliveryStatus` как числа.
- API работает без аутентификации. Стенд предназначен для локального запуска
  и демо. [Контракт API](../api/README.md).
