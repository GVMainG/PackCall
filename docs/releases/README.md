# Заметки о релизах

Заметки о релизе — `docs/releases/<tag>.md`, по файлу на тег, имя файла — полное имя тега
(`v0.5.0-beta.2.md`): что вошло, что не вошло, известные ограничения и исправления предыдущего
релиза. В заметках указывается commit SHA тега; SHA в заметках обязан совпадать с SHA тега
(расхождение — блокер тега, см. `../EVIDENCE.md`). Заметки с SHA тега фиксируются отдельным
коммитом после постановки тега — коммит не может содержать собственный SHA. Заметки `beta.2`
создаются в Story 1.22; для исторических `mvp`/`beta.1` заметки не пересоздаются (FR-21).
