# Контракт API

Baseline контракта API — `docs/api/openapi.v1.json`. Файла пока нет: baseline фиксируется в
Story 1.19, до этого каталог зарезервирован и контракт не считается замороженным. После
фиксации изменение API сравнивается с baseline, намеренные breaking-изменения записываются в
release notes. До 0.5 API не объявляется стабильным.
