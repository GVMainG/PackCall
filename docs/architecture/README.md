# Архитектура as-is

Здесь хранятся документы текущей архитектуры системы: компоненты, границы, потоки данных и
обоснование решений. Документ as-is создаётся в Story 1.20; архитектурные решения (ADR) —
в `../adr/`. Действующие архитектурные ограничения заданы спинным документом архитектуры
(AD-1…AD-8) и не переопределяются здесь.
