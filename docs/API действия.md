# GET

| Действие | Входные данные | Выходные данные |
| --- | --- | --- |
| Получить страницу кампаний | Номер страницы; размер страницы | Список моделей кампаний; количество элементов и страниц |
| Получить кампанию | `Id` кампании | Модель кампании; статистика доставок: всего, ожидают, отправляются, доставлены, ошибки |
| Получить страницу доставок кампании | `Id` кампании; номер страницы; размер страницы | Список моделей доставок; количество элементов и страниц |
| Получить доставку | `Id` доставки | Модель доставки |
| Получить страницу контактов | Номер страницы; размер страницы | Список моделей получателей; количество элементов и страниц |
| Получить контакт | `Id` контакта | Модель получателя |

# POST

| Действие | Входные данные | Выходные данные |
| --- | --- | --- |
| Создать кампанию | Название; текст сообщения | Модель созданной кампании; для статичного списка получателей созданы доставки со статусом «Ожидает» |
| Запустить кампанию | `Id` кампании | Модель кампании. Повторный запуск запущенной кампании возвращает её без изменения состояния |

# PATCH

| Действие | Входные данные | Выходные данные |
| --- | --- | --- |
| Изменить кампанию | `Id` кампании; изменяемые название и (или) текст сообщения | Модель кампании. Операция доступна только для кампании в статусе «Черновик» |

# DELETE

| Действие | Входные данные | Выходные данные |
| --- | --- | --- |
| Удалить кампанию | `Id` кампании | Подтверждение удаления кампании. Операция доступна только для кампании в статусе «Черновик» или «Завершена» |
