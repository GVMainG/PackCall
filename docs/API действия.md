# GET

- получить страницу кампаний вместе с количеством страниц и элементов
- получить конкретную кампанию со статусом и статистикой доставок: всего, ожидают, отправляются, доставлены, ошибки

- получить страницу доставок кампании вместе с количеством страниц и элементов
- получить конкретную доставку

- получить страницу контактов вместе с количеством страниц и элементов
- получить конкретный контакт

# POST

- создать кампанию
- запустить кампанию

# PATCH
