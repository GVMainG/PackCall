# CI-проверки исходников

## `check_utf8_sources.py`

Строгая проверка кодировки исходников C#: каждый git-tracked `*.cs` (расширение сравнивается
без учёта регистра) обязан декодироваться как UTF-8 без замены и не содержать U+FFFD — признак
того, что текст где-то был декодирован с потерей.

Команды:

- `python3 scripts/ci/check_utf8_sources.py` — проверить все tracked `*.cs`;
- `python3 scripts/ci/check_utf8_sources.py --paths FILE...` — проверить указанные файлы
  (используется тестами гейта).

Коды выхода: `0` — всё валидно, `1` — найден невалидный файл, `2` — ошибка окружения
(нет git, не git-репозиторий, файл не читается).

Ограничения контракта:

- BOM в начале файла допускается: это валидный UTF-8, он не скрывает текст;
- для файла сообщается только первое невалидное смещение; смещение — в байтах файла на диске,
  номер строки считается для LF, CRLF и CR;
- проверяется кодировка и целостность текста. Смысловая корректность текста (валидный UTF-8
  с неверными символами, но без U+FFFD) — вне контракта гейта.

Тесты гейта: `tests/tools/ci/test_check_utf8_sources.py`. В CI они запускаются в job
`utf8-sources` (`.github/workflows/ci.yml`) перед самой проверкой исходников.
