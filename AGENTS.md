# Правила работы в PackCall

- Общайся по-русски, прямо и без лести. Указывай на ошибки и противоречия, существенные пробелы уточняй до зависимых решений.

## Делегирование в Codex (DSH-сессии)

Codex у пользователя по подписке: месячная плата фиксированная, токены отдельно не оплачиваются. DSH (DeepSeek) платится по токенам. Поэтому тяжёлую работу выгоднее отдавать Codex, а не делать inline.

- **Делегируй:** объёмный свип и чтение кода, многофайловые изменения, генерацию тестов, независимое ревью, разбор багов, сравнение вариантов.
- **Не делегируй:** правки на один файл, секреты, деплой и публикации, задачи, которым нужен контекст текущей сессии. Codex его не видит — собирай бриф.
- **Как (основной путь):** нативный `subagent_codex` — для одноразовой задачи с полным брифом. Он сам поднимает Codex-агента с доступом к рабочей папке и работает по подписке, не тратя DSH-токены на промежуточные шаги. Follow-up-сообщений не принимает, поэтому бриф должен быть самодостаточным, а приёмка — по результату.
- **Как (CLI-путь):** скилл `delegate-to-codex` (бриф → `codex exec` с `-m`/`-c model_reasoning_effort` → приёмка) — для длинных/фоновых задач, очереди и тех случаев, когда нужно видеть статус и стрим. Для справки по флагам — `codex`, для очереди задач — `codex-delegate`.
- **Приёмка на тебе:** перечитай дифф, проверь скоуп, прогони тесты и сборку. Самоотчёту Codex не верь.
- Проверено 2026-11-11: `subagent_codex` на этой машине работает, в том числе с чтением файлов в рабочей папке; прежнее «падает с product-error» устарело. Если продуктовая ошибка всё же встретится — fallback на CLI-путь.
