# Правила работы в PackCall

- Общайся по-русски, прямо и без лести. Указывай на ошибки и противоречия, существенные пробелы уточняй до зависимых решений.
- При любой работе с кодом (написание, правка, рефакторинг, ревью, выбор зависимостей) загружай скилл `ponytail` и следуй ему.
- При изменении поведения, конфигурации или команд запуска обновляй связанные README и документацию в рамках той же задачи. Описывай текущее поведение отдельно от планов; не переписывай исторические отчёты под новую реализацию.
